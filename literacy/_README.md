# 学生作品の公開方法

このディレクトリの直下に、学籍番号を名前にしたディレクトリを作成し、学生から提出されたファイル一式を配置します。

```text
literacy/
├── 12345678/
│   ├── index.html
│   ├── sample_with_css.html
│   ├── sample.css
│   └── einstein.jpg
└── 87654321/
    ├── index.html
    └── css/
        └── main.css
```

上の例では、次のURLで各作品を閲覧できます。

- `https://yuteno.github.io/literacy/12345678/`
- `https://yuteno.github.io/literacy/12345678/index.html`

## 追加手順

1. `_template` ディレクトリ（授業で配布する4つのサンプルファイル）を、対象の学籍番号を名前にしてコピーします。
2. コピー先の `index.html`、CSS、画像などを、学生から提出されたファイルで置き換えます。
3. `index.html` が学籍番号ディレクトリの直下にあることを確認します。
4. 各HTMLの `<head>` 内に、テンプレートと同じ `robots` メタタグがあることを確認します。
5. ローカルで表示を確認した後、変更をコミットして GitHub に push します。
6. GitHub Pages のデプロイ完了後、上記形式のURLで確認します。

たとえば、リポジトリのルートで次のようにコピーします。

```console
cp -R literacy/_template literacy/12345678
```

## ファイル作成時の注意

- CSSや画像へのパスには、`sample.css` や `einstein.jpg` のような相対パスを推奨します。
- ファイル名の大文字・小文字は区別されます。HTML内の指定と実際のファイル名を一致させてください。
- トップページのファイル名は、小文字の `index.html` にしてください。
- 検索結果に掲載されにくくするため、各HTMLの `<head>` 内に `<meta name="robots" content="noindex, nofollow, noarchive">` を残してください。
- HTMLファイルの先頭に Jekyll の Front Matter（`---` で囲む設定）は付けないでください。通常のHTML/CSS/画像は内容を変更されずに公開されます。
- 学籍番号や作品を公開してよいか、本人の同意と所属機関のルールを事前に確認してください。

## 公開範囲について

- `literacy` はサイトのナビゲーションおよびHTML/XMLサイトマップからリンクしません。
- `/literacy/` 自体にはトップページを置かず、個別URLを知らない閲覧者には作品一覧を表示しません。
- 学籍番号の一覧ページは作成しません。
- `robots.txt` で検索エンジンに `/literacy/` 以下を巡回しないよう指定します。
- `_template` とこの説明ファイルは公開対象から除外します。学籍番号へ名前を変更したコピーだけが公開されます。

これらは「URLを知る人だけに案内する」ための措置であり、認証やアクセス制限ではありません。URLを推測した人や、URLを共有された人は閲覧できます。機密情報は置かないでください。
